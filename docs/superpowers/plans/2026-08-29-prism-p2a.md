# Prism Engine P2A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic native Rust mirror of Civic Foundry `WorldFoundationSnapshot` and `CadastralSnapshot`, prove cross-language query/validation/mutation parity, and keep TypeScript plus Save V9 fully authoritative throughout P2A.

**Architecture:** Add a transitional `prism-domain` workspace crate beside `prism-core`. TypeScript emits a versioned JSON envelope containing only existing authoritative world/cadastre snapshots; Rust decodes typed wire records, validates and canonicalizes them, builds immutable mirrors and derived indexes, computes a language-independent hash, and mutates isolated candidate cadastres for parity tests. A deterministic fixture generator and native parity CLI compare the same world/cadastre and mutation command streams without allowing native state to commit into the live game.

**Tech Stack:** Rust 1.98.0 / Rust 2024; `serde` + `serde_json` only as new Rust dependencies; Node 22 with TypeScript type stripping; existing TypeScript `WorldFoundation`, `CadastralGraph`, `CadastralMutationSystem`, Save V9, and `clipper2-ts` as parity oracles; GitHub Actions Linux + Windows gates.

**Spec:** `docs/superpowers/specs/2026-08-29-prism-p2a-design.md`

## Global Constraints

- Work on `feature/prism-p2a`, created from verified P1 head `e5a5c0e961d2654dbe023f1ae5a4c3b73baa0161`.
- Rust toolchain remains exactly 1.98.0 / Rust 2024.
- `engine/prism/Cargo.lock` remains committed; native verification uses `--locked`.
- `#![forbid(unsafe_code)]` remains mandatory in Prism-owned Rust crates.
- P2A may add only `serde` with derive support and `serde_json` as new Rust dependencies. No Rust geometry, spatial-index, hashing, RNG, FFI, or collection dependency.
- `prism-core` remains free of Civic Foundry domain semantics. `prism-core` must never depend on `prism-domain`.
- TypeScript `WorldFoundation`, `CadastralGraph`, `CadastralMutationSystem`, `CadastralRuntimeMutationService`, and Save V9 remain authoritative.
- No P2A API may mutate `SimulationCore` or write native state into the running game.
- Save V9 remains `saveVersion: 9`, `gameVersion: '0.9.0-urban-fabric'`. No Save V10 or native persistence.
- Imported hydrology/flood state is mirror data only. Do not port or transfer `HydrologyModel`, `FloodModel`, depression resolution, or design-storm authority.
- Persisted/domain string IDs remain the P2A identity contract; do not replace parcel/geography IDs with ECS GUIDs.
- Canonical state must not depend on JSON object-key order, source set-like collection order, map iteration order, worker timing, profiler timing, or diagnostic metadata.
- Every task ends with a fully green contract for the behavior that task claims and a focused commit.
- Do not begin P2B authority-transfer work in this plan.

## Execution Stop Conditions

Stop and request a new architecture decision instead of weakening parity if:

1. the internal Rust polygon kernel cannot reproduce the committed TypeScript geometry oracle;
2. parity would require changing Save V9 semantics;
3. a fix would make native P2A a live gameplay mutation source;
4. a divergence is an intentional semantic improvement rather than current-behavior parity;
5. a required Rust dependency exceeds the approved `serde`/`serde_json` allowance;
6. hydrology solver authority would have to move to satisfy P2A.
